# Крестики-нолики с искусственным интеллектом

## О проекте

Это обычная игра в крестики-нолики, написанная на Python. В ней можно играть против компьютера, который выбирает свои ходы с помощью алгоритма Minimax.

У игры есть графический интерфейс, поэтому играть можно мышкой, без ввода команд в консоль.

## Что умеет игра

- Игровое поле размером 3×3.
- Игра против компьютера.
- Компьютер выбирает ходы с помощью алгоритма Minimax.
- Проверка победы, поражения и ничьей.
- Подсчёт результатов нескольких игр.
- Возможность начать новую игру.

## Что использовалось

- **Python** — язык программирования.
- **Tkinter** — для создания окна игры.
- **Minimax** — алгоритм, который помогает компьютеру выбирать лучшие ходы.

## Как запустить игру

1. Установить Python 3, если он ещё не установлен.
2. Скачать или клонировать этот репозиторий.
3. Открыть папку проекта в терминале.
4. Запустить игру командой:

```bash
py main.py
```

Дополнительные библиотеки устанавливать не нужно, если Tkinter уже доступен в Python.

## Правила игры

Игрок играет за **X**, а компьютер — за **O**.

Чтобы сделать ход, нужно нажать на свободную клетку. После этого компьютер автоматически сделает свой ход.

Побеждает тот, кто первым соберёт три одинаковых символа по горизонтали, вертикали или диагонали. Если свободных клеток не осталось и никто не победил, получается ничья.

## Как работает Minimax

Minimax — это алгоритм, который помогает компьютеру выбирать хороший ход.

Перед тем как сделать ход, компьютер рассматривает возможные варианты продолжения игры и оценивает, чем они могут закончиться.

В этой игре:

- победа компьютера оценивается положительно;
- победа игрока оценивается отрицательно;
- ничья оценивается нулём.

Компьютер старается выбрать ход с лучшим результатом для себя и учитывает возможные ответы игрока.

Алгоритм проверяет все возможные продолжения игры, поэтому при правильной игре компьютер не должен проигрывать. Также он старается выиграть быстрее, если есть такая возможность.

## Ограничение глубины поиска

В игре нет ограничения глубины поиска. Поле всего 3×3, поэтому компьютер может проверить все возможные варианты до конца игры. Для крестиков-ноликов это не требует слишком много вычислений.
